## English

- Windows notifications now display SSUTime as the sender.
- Clicking a deadline notification now restores SSUTime and brings it to the foreground.
- Taskbar and Microsoft Store icons now preserve their transparent rounded corners.

## 한국어

- Windows 알림 발신자 이름이 SSUTime으로 표시되도록 수정했어요.
- 마감 알림을 클릭하면 SSUTime 창이 복원되어 앞으로 표시돼요.
- 작업표시줄과 Microsoft Store 아이콘의 둥근 투명 모서리가 유지되도록 개선했어요.
